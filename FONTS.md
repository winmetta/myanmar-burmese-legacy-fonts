# Font catalogue

Every font in this repository, grouped by kind and listed once per unique
content (SHA-256). The same font often appears as several files, with
different file names or in different sources. They are listed together in
the last column.

The font name, style and version come from each font's own name table.
Categories are assigned from the font's glyph coverage, its name and the
folder it came from, so a few fonts may sit in the wrong group. See the
[README](README.md) for the sources and how each was collected.

Web and desktop formats (`.ttf`, `.otf`, `.woff`, `.woff2`, `.eot`, `.svg`)
of the same font have different content, so each format is its own row.
The `.eot` and `.svg` files take the name of the font file next to them.
