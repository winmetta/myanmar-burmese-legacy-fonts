# dafontfree.net

Myanmar legacy fonts downloaded from <https://www.dafontfree.net/search?key=wininnwa&alias=fonts&page=1> (58 fonts, search results for "wininnwa"). Each font's zip was downloaded with the site's **Download zip** button and only the `.ttf` files were extracted into this directory.

These are legacy, non-Unicode (Win Innwa / Zawgyi-style) fonts collected here so people working with Burmese text can download and use them. The source pages label them "Download free for Personal Use".
