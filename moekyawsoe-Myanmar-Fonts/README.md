## Files removed from this copy (Win Metta)

This repository tracks fonts only, so this file from the original source was
deleted from this copy:

- `fonts.reg`: a Windows registry file that lists system fonts (it edits the
  registry, and is not needed to install a font).

- `zawgyi_fonts_installer.rar`: a Windows Zawgyi installer (`.exe`, `.msi` and
  `.dll` files, plus a keyboard picture).
- `IEZawGyiGtalkfont.rar`: a single `.exe` installer.
- `WinRAR 3.51.rar`: the WinRAR 3.51 installer together with a `UniPatch+Key`
  folder (`Unipatch.exe`, `Rarreg.key`), a licence bypass for that program.

None of the three archives contained fonts.

## Archive extracted and duplicates (Win Metta)

- `Myanmar Fonts TTF Series 2.rar` was extracted to
  [`Myanmar Fonts TTF Series 2/`](Myanmar%20Fonts%20TTF%20Series%202/) (310 TTFs, 60 OTFs, 59 `.pfb`, 86 `.pfm` and 6
  `.pss` files) and the rar was deleted.
- No duplicates were removed: no two files share both contents and name. A few
  files with identical contents under different names were kept
  (`MY_SH000.PFM`/`MY_SHWE.PFM` and `MY_SH000.PSS`/`MY_SHWE.PFB`).
